# Spreadsheet Activities

Reference guides for the in-class spreadsheet activities. Each one covers a set of chapters from *[The Most EXCELlent OER Spreadsheets Textbook](https://minnstate.pressbooks.pub/spreadsheets2025/)* using an environmental monitoring dataset instead of the textbook's generic examples. Open any activity below — they render right in your browser, phone included.

## Activities

- **[Spreadsheet Fundamentals](01-spreadsheet-fundamentals.html)** — Chapters 1–3: entering data, formatting, AutoSum, charts
- **[Formulas, Statistical Functions & Sorting](02-formulas-statfunctions-sorting.html)** — Chapters 5, 6, 18
- **[Importing Data & PivotTables](03-importing-data-pivottables.html)** — Chapters 21, 22
